## Repository Purpose

This repository is created to maintain and share the programs performed for the **Operating Systems (CEC-301) laboratory** in the 5th semester. The programs cover core operating system concepts, including process and thread management, CPU and disk scheduling, process synchronization, deadlock avoidance, memory management, page replacement, and file allocation.

## Topics Covered

- Linux system calls and process management
- POSIX thread creation and management
- CPU scheduling
- Process synchronization and semaphores
- Deadlock avoidance
- Memory allocation strategies
- Page replacement
- Disk scheduling
- File allocation methods
